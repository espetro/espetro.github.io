# `.agents/docs/screens/`

ASCII "screen" files are the canonical human-readable map of every
public-facing route on illo.fyi. `screen-INDEX.txt` is the directory; each
`screen-*.txt` describes one route's layout, copy, and interaction contract.

Keep these in sync when changing page structure, section order, or primary
copy. Regenerate by reading the corresponding `src/pages/**` file and the
components it renders.

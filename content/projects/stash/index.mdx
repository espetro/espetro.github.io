Stash turns your open browser tabs into a single shareable link or saves them for later — privately, locally, and AI-ready. Built for researchers, engineers, and founders who think in browser tabs.

## Features

- Convert open tabs into a single shareable link
- Save tab collections locally for later
- Privacy-first: all data stays on your machine
- AI-ready context format for downstream tools

## Tech Stack

Built with TypeScript, Astro, and Python, Stash prioritizes local-first data handling and seamless tab context management.

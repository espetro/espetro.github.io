`unplugin-agent-plugins` provides a universal adapter layer for integrating AI agent capabilities into any JavaScript bundler. Built on the [unplugin](https://github.com/unjs/unplugin) foundation, write the plugin once and it runs on Vite, Webpack, Rollup, esbuild, and more.

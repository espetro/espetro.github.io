Calca is an AI-powered design tool that generates polished HTML/CSS variations from natural language descriptions. Describe any design you envision and get production-ready code with real images.

## Features

- Natural language to design generation
- Multiple HTML/CSS variations per prompt
- Real image integration in generated designs
- Landing page and website building capabilities

## Tech Stack

Built as a set of composable packages in TypeScript, targetting both desktop and web platforms, Calca leverages generative AI and text-to-code techniques to bridge the gap between design intent and implementation.

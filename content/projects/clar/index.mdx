Clar is a privacy-first, local-first AI agent for email. It connects to any IMAP inbox and runs entirely on your machine — no cloud sync, no data leaving your device.

## Features

- Fully local execution with no cloud dependency
- Connects to any IMAP-compatible inbox
- Reversible actions by default
- Auditable, transparent operations
- Early access / private beta

Danzabilidad is a web application designed for dance and movement analysis. It provides tools and visualizations to help dancers, instructors, and researchers analyze movement patterns, track progress, and gain insights into dance performance.

- Movement pattern analysis
- Interactive visualizations
- Performance tracking
